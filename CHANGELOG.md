# Changelog

Semua perubahan penting pada proyek Website Resmi SMA PGRI 1 Tulungagung dicatat dalam file ini.

## [Unreleased]

### Added
- Modul Kurikulum dengan dukungan dokumen PDF, gambar asli untuk unduhan, dan preview WebP.
- Modul SPMB untuk informasi, file informasi, dan brosur.
- Modul Guru & Karyawan menggunakan satu fondasi data dengan halaman publik terpisah.
- Modul Alumni Pilihan dengan maksimal 4 profil aktif.
- Integrasi pendataan alumni melalui Google Forms dan Google Sheets.

### Changed
- Terminologi informasi penerimaan siswa dari PPDB menjadi SPMB pada website publik.
- Struktur navigasi publik menjadi Beranda, Profil, Akademik, Informasi, Jejak & Karya, dan Kontak.
- Halaman Profil dipisahkan menjadi Profil Sekolah, Sejarah, Data Guru, dan Data Karyawan.
- Pendataan alumni tidak lagi disimpan pada database Laravel.
- Dokumentasi proyek diperbarui menyesuaikan kebutuhan fitur terbaru.
